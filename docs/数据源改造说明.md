# 数据源改造说明（政策 / 就业板块）

> 目标：把"政策"和"就业"两个板块的数据源，从"泛化滚动新闻"换成**真正面向大学生就业的政策、市场行情与国家级政策**的内容。
> 本文档先说明问题与方案，再对应 `src/data/feeds.json`、新增抓取脚本与工作流的代码改动。

---

## 1. 现状与问题

当前 `feeds.json` 中，"政策/就业"相关只有两条源：

| 源 | category | 实际问题 |
|----|----------|----------|
| 中新网滚动 `scroll-news.xml` | `政策` | 这是**全站滚动新闻**（时政/社会/国际/体育全混在一起），归类成"政策"名不副实，几乎拿不到"国家政策/就业政策"类内容 |
| 中新网教育 `edu.xml` | `就业` | 是**泛教育新闻**（考试/院校/留学），并不聚焦"大学生就业政策" |

结果：用户想要的「大学生就业政策 / 市场行情 / 国家政策」在站点里基本缺位，板块内容严重不符合预期。

### 根因（技术约束）
采集器 `scripts/collect-rss.js` **只支持 RSS/Atom**，而教育部、中国政府网这类"真正的政策源"**不提供稳定的 RSS 订阅**。纯靠 RSS 永远抓不到教育部原文的"高校毕业生就业创业"政策文件。

---

## 2. 改造方案

采用「**RSS 精筛 + 教育部政策目录 HTML 抓取**」两条腿：

### 2.1 RSS 源重新分配（已实测可达，从本机/广西与美国 GitHub 服务器均可连通）

| 板块(category) | 新数据源 | 说明 |
|---------------|----------|------|
| `政策`（国家政策） | 人民网时政 `people.com.cn/rss/politics.xml`（100 条） | 国家级时政/政策主源 |
| `政策`（国家政策） | 中新网时政 `chinanews.com.cn/rss/politics.xml`（10 条） | 补充时政 |
| `就业`（大学生就业政策） | 中新网教育 `edu.xml` | 保留，作为教育/就业动态 |
| `就业`（大学生就业政策） | 中新网社会 `society.xml` | 补充就业/民生类社会新闻 |
| `财经`（市场行情） | 中新网财经 `finance.xml`（30 条） | 经济/就业市场行情 |
| ——（删除） | ~~中新网滚动 `scroll-news.xml`~~ | 全站混杂，移出"政策"归类 |
| ——（删除） | ~~BBC中文~~ | 从美国 GitHub 服务器稳定超时，长期 0 条，拖累流水线 |

> 保留：`AI`、`科技`、`开发`、`综合`（注：原 `综合` 仅 BBC 一个源，删除 BBC 后暂不保留"综合"，避免空板块）。

### 2.2 新增「教育部政策目录 HTML 抓取」（核心增量）

直接抓取教育部"高校毕业生就业创业"政策文件目录页，这是**最贴合"大学生就业政策"的权威源**：

- 目录页：`https://www.moe.gov.cn/jyb_xxgk/xxgk/neirong/fenlei/sxml_gdjy/gdjy_bysjycy/bysjycy_bsxwj`
- 解析规则：提取 `href` 含 `srcsite/A15/s3265` 的 `<a>` 标签，取标题文字，用 `new URL(href, 目录页URL)` 还原为绝对地址。
- 产出：每条政策 = `{ title, url, category: "就业", source: "教育部" }`，并入 `public/data/raw-articles.json`（与 RSS 同源同构，下游 AI 摘要/翻译/聚类照常处理）。
- 实测：已成功解析出 2026-06、2026-05、2026-04… 的"国聘行动""春季促就业攻坚行动""双惠行动"等真实政策条目，标题与链接均正确。

### 2.3 流水线接入

新增脚本 `scripts/collect-moe-policy.js`，并在：

- `package.json`：增加 `"collect:moe": "node scripts/collect-moe-policy.js"`，并在 `update` 串联中加入它（放在 `collect` 之后）。
- `.github/workflows/collect-news.yml`：在 `Collect RSS` 步骤之后增加 `Collect MOE Policy (HTML)` 步骤。

> 工作流 `timeout-minutes` 已在上次排查中由 20 提升到 60，足以容纳 HTML 抓取 + AI 处理。

### 2.4 前端分类样式修正

`src/composables/useCategory.js` 中 `政策` 的 `icon` 字段是乱码字符（`️`），改成一个正常 emoji（如 `🏛️`）。新增的 `政策/就业/财经` 分类本就已存在于 `CATEGORY_MAP`，无需新增分类，板块结构保持不变。

---

## 3. 实施步骤（对应代码改动）

1. 改写 `src/data/feeds.json`（见 §2.1）。
2. 新建 `scripts/collect-moe-policy.js`（见 §2.2）。
3. 在 `package.json` 增加 `collect:moe` 脚本并并入 `update`。
4. 在 `collect-news.yml` 增加 HTML 抓取步骤。
5. 修正 `useCategory.js` 的 `政策` icon 乱码。
6. 本地验证：`node scripts/collect-moe-policy.js` 与 `node scripts/collect-rss.js` 均可运行且 `raw-articles.json` 正确并入新条目。

---

## 4. 风险与验证

| 风险 | 说明 / 缓解 |
|------|------------|
| 教育部目录页改版 | HTML 解析依赖固定路径 `srcsite/A15/s3265`；脚本全程 try/catch，失败不影响 RSS 主流程 |
| 目录页仅列最新约 20 条 | 每次运行都从实时目录重新并入，板块始终展示"最新政策"；历史老政策会自然滚动出目录 |
| 7 天过滤误删政策 | `collect-rss.js` 会对 raw 做 7 天过滤，但 `collect:moe` 在每次运行都会重新并入目录中的现行政策，故不会丢 |
| 美国服务器连通性 | 中新网/人民网/教育部均已在广西本机实测 200，美国 GitHub 对中新网类源历史上连通，风险低 |

**验证方式**：推送后到仓库 `Actions → Collect News → Run workflow` 手动触发一次，检查 `public/data/raw-articles.json` 中是否出现 `source:"教育部"` 的 `就业` 条目，以及"政策/就业/财经"三板块是否有对应新内容。
